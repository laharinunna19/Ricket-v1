# 🏏 Ricket

## Code. Play. Score.

Ricket is a playful coding challenge game inspired by cricket.

Instead of simply solving coding questions, players convert their coding performance into cricket runs.

---

## 🎯 Concept

1. Choose your programming language.
2. Choose an IPL team.
3. Select difficulty.
4. Start the match.
5. Solve coding challenges within the time limit.
6. Your performance determines the number of runs.
7. Six balls = one over.
8. Three overs = one match.

---

## 🏏 Scoring System

| Coding Score | Cricket Result |
|---|---|
| 90–100% | 6 Runs |
| 70–89% | 4 Runs |
| 40–69% | 2 Runs |
| 1–39% | Dot Ball |
| Time Expired | Wicket |
